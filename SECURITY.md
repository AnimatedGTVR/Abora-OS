# Security Policy

Abora provides security fixes for the current stable release. Edge is a development channel and is not a security-supported release.

## Report a vulnerability

Do not open a public issue. Use GitHub Private Vulnerability Reporting when available. Otherwise, contact the maintainers through an official Abora channel and ask for a private reporting method.

Include the affected version, component, reproduction steps, impact, relevant logs, and any suggested fix. Remove passwords, tokens, private keys, Wi-Fi credentials, and personal information.

Please allow reasonable time for investigation and a coordinated fix before disclosure. Vulnerabilities in upstream packages should normally be reported upstream unless Abora's configuration or tooling caused the problem.

This policy covers official Abora images, installers, update and recovery tools, repositories, and project infrastructure.
