# Abora Tools

The `abora` command groups distro-specific operations:

```sh
abora doctor
abora update --check
sudo abora update
abora recovery
abora setup
abora desktop list
abora config
abora network
abora logs --lines 200
abora support-report
```

## Responsibilities

- **Abora:** installation, updates, hardware setup, recovery, diagnostics, desktops, and gaming.
- **ANIX:** system profiles, generations, snapshots, rebuild tests, and rollback.
- **TinyPM:** application discovery and package-provider operations.
- **Labs:** experimental comparisons; not part of normal system management.

Run `COMMAND --help` for the current arguments. Avoid copying old commands from third-party posts because Edge changes quickly.
