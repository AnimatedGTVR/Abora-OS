# Abora Labs

Abora Labs compares experimental implementations of the same component under one specification and test set. It helps Abora choose technology with evidence instead of preference.

```sh
abora-labs list
abora-labs validate
abora-labs compare updater
```

Each area contains shared requirements and one directory per implementation. Results record build, test, run, size, timing, and human review separately. Labs does not automatically promote experiments into production.

See [CLI](cli.md), [architecture](architecture.md), and [manifest reference](manifest.md).
