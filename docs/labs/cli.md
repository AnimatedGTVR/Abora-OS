# abora-labs CLI

```sh
abora-labs list
abora-labs show AREA
abora-labs validate
abora-labs run AREA IMPLEMENTATION
abora-labs compare AREA
abora-labs report AREA
```

Use `--help` for current options. Stage processes receive `ABORA_LABS=1` and the workspace path. Exit 0 means success, 1 means an experiment or validation failure, and 2 means invalid usage or configuration.
