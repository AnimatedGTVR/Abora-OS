# Abora OS Roadmap

## v4.2 Solstice

Solstice focuses on a safer, simpler Abora:

- reduce duplicated commands and code
- clarify the roles of `abora`, ANIX, TinyPM, and Labs
- improve installer errors and saved logs
- strengthen diagnostics, recovery, updates, and rollback
- test clean installation on every main edition
- document supported and experimental features clearly

## Later releases

Planned work includes simpler graphical configuration, better software discovery, smoother desktop setup, broader hardware testing, and tighter CLI/GUI consistency.

Dates and features may change when reliability work takes longer than expected. Release readiness is determined by testing, not the calendar.
