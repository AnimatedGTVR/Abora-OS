# Code of Conduct

## Our Community

Abora OS is an open-source project built by people with different backgrounds, experience levels, and perspectives.

Our goal is to create a welcoming, respectful, and collaborative environment where everyone can contribute, learn, and share ideas.

By participating in the project, you agree to follow this Code of Conduct.

## Be Respectful

Please:

* Be respectful and courteous.
* Be patient with new contributors.
* Assume good intentions.
* Give constructive feedback.
* Respect differing opinions and technical approaches.
* Help others learn when you can.

Healthy discussion and disagreement are a normal part of open-source development. Focus on the ideas, not the individual.

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment or personal attacks.
* Discrimination based on personal characteristics.
* Threats or intimidation.
* Hate speech.
* Trolling or intentionally disruptive behavior.
* Sharing private information without permission.
* Spam or repeated off-topic discussions.

## Project Discussions

When discussing ideas, pull requests, or issues:

* Keep conversations on topic.
* Explain your reasoning when suggesting changes.
* Accept constructive criticism.
* Respect project maintainers' decisions.
* Remember that everyone is here to improve the project.

Not every proposal will be accepted, and that's okay.

## Reporting Issues

If someone is violating this Code of Conduct, please contact the project maintainers or use GitHub's reporting tools if appropriate.

Reports will be reviewed as fairly and confidentially as possible.

## Enforcement

Project maintainers may take appropriate action if this Code of Conduct is violated.

Depending on the situation, this may include:

* A private warning.
* Removal of inappropriate content.
* Temporary restrictions.
* Permanent removal from the community.

Enforcement decisions are made at the discretion of the maintainers.

## Scope

This Code of Conduct applies to:

* GitHub Issues
* Pull Requests
* GitHub Discussions
* Project documentation
* Community spaces managed by the Abora OS project
* Other official project communication channels

## Attribution

This Code of Conduct is inspired by the principles of the Contributor Covenant while being adapted for the Abora OS project.

## Thank You

Thank you for helping make Abora OS a welcoming, respectful, and collaborative open-source project.
