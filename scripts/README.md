# Abora Scripts

- `core/`: command routing, UI helpers, and ANIX
- `install/`: live boot, installer, adoption, setup, and build entry points
- `config/`: desktop, dotfiles, theme, and configuration tools
- `apps/`: application, Gaming, Labs, and custom-package tools
- `support/`: update, diagnostics, recovery, feedback, and reports
- `release/`: builds, checks, packaging, metadata, and VM helpers

Keep shell entry points small, reuse shared helpers, quote inputs, and preserve actionable errors. Run `make check` after changes.
